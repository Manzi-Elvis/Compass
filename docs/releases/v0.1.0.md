# COMPASS v0.1.0: Foundation

**Date:** 2026-11-05

## Summary

Repository, git workflow and monorepo skeleton. No product features yet.

## Added

- Git branching model (`main`, `dev`, `ft/*`, `fix/*`, `chore/*`, `release/*`) and contribution rules
- pnpm workspaces and Turborepo task pipeline
- Strict shared TypeScript base config
- Prettier, EditorConfig, line-ending normalization and environment template
- Folder structure from the master specification
- ADR 0001: modular monolith

## Upgrade notes

First release. Run `pnpm install`. Requires Node 22+.
