# COMPASS v0.2.0: Tooling and Shared Contracts

**Date:** 2026-11-05

## Summary

Automated quality checks and the first shared package. Still no product UI.

## Added

- **Commit quality:** Husky, lint-staged (Prettier on staged files) and commitlint (one-line Conventional Commits)
- **`@compass/shared`:** Zod schemas and inferred types for tasks and cursor pagination, with Vitest tests
- **ESLint:** typed rules and package-boundary checks
- **CI:** GitHub Actions runs format, lint, typecheck, test and build on every push and pull request
- **Dependabot** and a pull request template
- **ADR 0002:** TypeScript pinned to 6.x until typescript-eslint supports 7

## Fixed

- Missing package manifest and tsconfigs for `@compass/shared` in the first merge
- Task update schema injected a default priority into partial updates, which could silently overwrite an existing priority

## Repository settings

- Rulesets protect `main`, `dev` and `v*` tags: pull requests and passing CI required, no force pushes, no deletions

## Upgrade notes

Run `pnpm install` so Husky hooks are installed. Requires Node 22+.
